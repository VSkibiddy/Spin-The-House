# Spin the House

A roulette survival game made in Unity. You are trapped by the House and owe it a debt. Bet, spin and bank your chips to pay each deadline before your spins run out. Fail, and the trapdoor opens.

---

## How to play

1. **Pick a color.** Red or Black pays 2×, Green (the single 0) pays 36×.
2. **Set your bet** with `−` / `+` (steps of 10) or **ALL IN**, then press **SPIN**.
3. **Bank your chips** with **DEPOSIT**. Chips in the ATM are safe from bad bets, earn interest after every spin, and pay off the debt.
4. **Pay the deadline.** As soon as the ATM covers the debt, it is paid and the next deadline starts. Every unused spin gives a bonus of +10 chips. Out of spins? You can still deposit to pay.
5. **Survive.** Each deadline the debt grows and the wheel spins faster. From deadline 3, purple **cursed pockets** pay nothing.

You lose when the debt can no longer be paid. Your best deadline is saved as the highscore.

### Controls

| Action | Input |
|---|---|
| Choose color, bet, spin, deposit | Mouse |
| Pause / back | `Esc` or the pause button (top right) |

## Features

- Debt / deadline progression
- ATM banking with interest that grows each deadline
- Fixed-step deposit that scales per deadline and shrinks to the exact amount still owed
- Early-payoff bonus for unused spins
- Dynamic music that switches to a sinister track at each cursed deadline
- Roulette wheel generated at runtime (37 pockets, dividers, wooden cone, brass turret) with a snap-to-pocket fix
- How to Play screen (shown automatically on the first game)
- Music and SFX volume sliders, saved between sessions
- LED-style HUD and result display, casino-chip buttons, custom menu and game over art with traced hover glows
- Stage spotlight with a visible light beam, custom pixel cursor, studio splash logo

## Under the Hood

| System | How it works |
|---|---|
| Core gameplay loop | Bet → spin → bank chips → pay the deadline, repeated with rising debt |
| Main menu | Custom menu scene with Play and Quit |
| Pause menu | Resume, How to Play, Quit to menu, plus volume sliders |
| Audio | Main music, a sinister track for cursed deadlines, rolling-ball sound, win / lose / paid sound effects |
| Custom shader | `PulseGlow` (Shader Graph): pulsing emissive glow on cursed pockets |
| Physics interaction | Rigidbody ball on a kinematic spinning wheel; pocket trigger colliders decide the result |
| Difficulty scaling | Debt grows ×1.5 per deadline, cursed pockets from deadline 3, faster wheel |
| Highscore | Best deadline saved with `PlayerPrefs` and shown on the game over screen |
| Post processing | Vignette tightens as spins run out, Bloom flash on wins, Chromatic Aberration on losses |
| VFX | Shuriken coin burst on wins, dust particles in the stage light |
| Singleton | `GameManager.Instance` |

## Opening the project

1. Clone or download this repository.
2. Open the folder with **Unity 6** (Universal Render Pipeline) through Unity Hub.
3. Open `Assets/Scenes/MainMenu` and press Play.

Only `Assets`, `Packages` and `ProjectSettings` are included. Unity regenerates everything else on first open.

## Scripts

| Script | Purpose |
|---|---|
| `GameManager` | Singleton holding chips, debt, spins, deadlines, rules, UI and highscore |
| `RouletteWheel` | Builds the wheel at runtime, runs the spin sequence and reports the winning number |
| `Pocket` | Trigger on each pocket that registers where the ball rests |
| `PostFXController` | Drives Vignette, Bloom and Chromatic Aberration from gameplay events |
| `MusicManager` | Music crossfades, sinister track, fade-out on game over |
| `PauseMenu` | Pause, resume, How to Play screen, quit to menu |
| `VolumeSettings` | Music and SFX sliders saved with PlayerPrefs |
| `MainMenu` | Loads the game or quits |
| `SpinPips` | Spin counter bars in the HUD |
| `LightBeam`, `LightFlicker` | Visible spotlight cone and flickering room light |
